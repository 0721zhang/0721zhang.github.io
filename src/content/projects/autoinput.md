## 项目起因

有些网页（特指超星学习平台）的输入框只能手动录入内容，不允许使用 Ctrl + V 粘贴。

对于几百字甚至上千字的文本，如果全部重新敲一遍，实在有点浪费时间。

于是就想到了一个简单的办法：既然网页不接受粘贴操作，那能不能让电脑模拟键盘，把复制好的文字自动输入进去？

于是有了这个基于 AutoHotkey v2 的小脚本，只需要一个快捷键就可以搞定。

## 主要功能

* **快捷键输入：** 按下 Ctrl + Shift + C，自动输入剪贴板中的文字。
* **支持中文：** 可以输入中文、英文、数字及常见标点符号。
* **支持多行文本：** 自动将复制内容中的换行转换为回车操作。
* **可调整输入速度：** 修改代码中的 Sleep 数值即可改变每个字符的输入间隔。
* **快速退出：** 按 F8 可以随时终止脚本。
* **轻量运行：** 无需图形界面，启动后在后台等待快捷键。

## 使用教程

### 1. 安装 AutoHotkey v2

前往 AutoHotkey 官方网站下载并安装：

https://www.autohotkey.com/

注意，需要使用 v2 版本。

### 2. 下载并运行脚本

下载本项目的压缩包，解压后双击其中的 `.ahk` 文件运行（不用在应用内部操作，但需要保持应用进程还在）。

运行成功后，Windows 任务栏的托盘区域会出现 AutoHotkey 图标。

### 3. 开始自动输入

首先，选中需要输入的文字，按 Ctrl + C 复制。

接着，打开目标网页，点击需要填写内容的输入框，使其获得焦点。

最后按下 **Ctrl + Shift + C**。

脚本会读取剪贴板内容，并模拟键盘逐字输入。

### 4. 停止脚本

按下 **F8**，即可退出脚本。

再次使用时，只需重新双击 `.ahk` 文件运行。

## 工作原理

普通粘贴操作通常通过剪贴板和粘贴事件，把整段文字一次性插入输入框。

本项目采用不同的方式：

读取 Windows 剪贴板中的文本，然后利用 AutoHotkey 的 `SendText` 功能，逐字符模拟文本输入。

所以它并不是修改网页内容或解除网页本身的限制，而是尝试通过模拟键盘输入完成文字录入。

## 注意事项

1. 本项目仅支持 Windows 系统，需要安装 AutoHotkey v2。
2. 部分网页可能拒绝模拟输入，实际兼容性取决于网页实现。
3. 使用前需要将光标放在正确的输入框，否则可能输入到其他窗口。
4. 某些网页会将回车识别为提交操作，输入多行内容前建议先测试。
5. Ctrl + Shift + C 在部分浏览器中原本用于打开元素检查工具，脚本运行时可能覆盖该快捷键。
6. 本项目仅提供文本自动输入功能，不具备自动答题、识别题目或提交作业的功能。
